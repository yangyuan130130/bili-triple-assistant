# B站一键三连 · 智能分类收藏

一个 Tampermonkey 油猴脚本：在 B 站普通视频页显示分类预览，**只有你主动点击按钮后**，才执行点赞、投币、收藏；收藏时按视频标题、分区和标签判断类型，复用同名收藏夹，不存在则自动新建**私密收藏夹**。

## 功能

- 一键完成：点赞 + 投币（1/2 枚可配置）+ 收藏
- 根据标题、分区、标签做本地规则分类，并显示命中依据与得分
- 目标收藏夹名称在执行前可修改，也可以从已有收藏夹中选择
- 同名收藏夹直接复用；不存在时自动创建，默认私密
- 执行前重新查询状态：已点赞、已投币、已在目标收藏夹的项目不重复执行
- 点赞、投币、收藏分别报告「成功 / 此前已完成 / 失败 / 结果未知 / 未执行」
- 单个项目失败时保留其他项目的真实结果，不虚报全部成功
- 写操作只提交一次，不自动重试；网络结果不明时会明确提示核对
- Shadow DOM 隔离面板、深浅主题、分类规则本地保存、诊断日志

## 安装

1. Edge 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. Tampermonkey 面板 →「添加新脚本」。
3. 删除编辑器模板，粘贴 `bili-triple-assistant.user.js` 全文，`Ctrl + S` 保存。
4. 确认脚本已启用，并允许其连接 `api.bilibili.com`。
5. 在当前浏览器登录 B 站，再打开 `https://www.bilibili.com/video/...` 页面。

也可以把 `.user.js` 文件拖进浏览器窗口安装。

## 使用

1. 打开视频后，右下角会出现「一键三连 · 智能收藏」面板。
2. 面板先执行只读预览，显示视频标题、登录状态、判断类型、命中标签和目标收藏夹。
3. 核对「收藏到」输入框。名称相同会复用已有收藏夹；不存在则显示「将自动新建为私密」。
4. 点击「一键三连」。默认投 1 币，可在「设置」中改为 2 币。
5. 查看逐项结果。如果某一项失败，另外两项仍可能已经成功，以面板逐项状态为准。

刷新预览不会产生点赞、投币、收藏或建夹操作。

## 分类规则

分类完全在本地完成，不调用外部 AI 服务。规则按以下权重评分：

| 命中方式 | 分值 |
|---|---:|
| 标签与关键词完全一致 | 5 |
| 标签包含关键词 | 3 |
| 标题包含关键词 | 2 |
| 分区包含关键词 | 1 |

同一关键词只取最高权重；默认至少 2 分才采用分类。多条规则同分时，标签得分高者优先，仍相同则排在前面的规则优先。没有规则达到阈值时使用「未分类」。

在「设置」里可以编辑 JSON。最小示例：

```json
[
  {
    "name": "计算机考研",
    "folder": "408学习",
    "keywords": ["计算机考研", "王道", "408", "数据结构"],
    "exclude": ["英语"],
    "minScore": 2
  }
]
```

- `name`：面板显示的类型。
- `folder`：目标收藏夹名称；省略时使用 `name`。
- `keywords`：关键词数组。
- `exclude`：可选，命中一条减 4 分。
- `minScore`：可选，默认 2。

设置保存在浏览器 `localStorage` 的 `bta:settings:v1`，清缓存会丢失。

## 防重复与异常处理

执行顺序为：

```text
重新读取登录态、点赞状态、投币状态、收藏夹列表
  → 点赞（已赞则跳过）
  → 投币（已投过则跳过，不擅自补投）
  → 目标收藏夹不存在则新建私密收藏夹
  → 加入目标收藏夹（不移出其他收藏夹）
```

- 接口 `65006`（重复点赞）和 `11201`（已经收藏）按已完成处理。
- 投币达到上限、硬币不足、不能给自己的视频投币等错误会如实显示，脚本不会绕过限制。
- 登录失效或 CSRF 校验失败后，停止后续写操作。
- 新建收藏夹遇到网络异常时，会先只读重查；若其实已建成功则直接复用，不重复创建。
- B 站接口没有跨操作事务，因此可能出现「点赞成功、投币失败、收藏成功」这类部分成功状态。
- 快速切到另一个视频后，旧任务停止后续操作，避免把后续请求打到错误上下文。

## 为什么没有直接用官方三连接口

B 站网页端确实有 `archive/like/triple`，但它固定投 2 币并收藏到默认收藏夹，无法指定分类收藏夹。因此脚本使用独立的点赞、投币和收藏接口。

## 隐私与权限

- 不保存、不上传 Cookie、SESSDATA、bili_jct 或任何登录凭据。
- `bili_jct` 只在当前页面读取并放入 B 站官方接口要求的表单中，不会写入日志。
- 请求只发往 `https://api.bilibili.com`。
- 新建收藏夹使用 `privacy=1`（私密）。
- 不会自动给打开的视频三连，不会批量遍历视频，也不会自动关注 UP 主。
- 投币不可撤回，请在点击前核对投币数量和目标视频。

## 已知限制

- 只支持普通视频稿件（BV/av 页面），不支持番剧、课程、直播和动态。
- 分类是可编辑规则做出的初步判断，不等同于语义理解；存在误判，执行前请核对目标收藏夹。
- 收藏夹只按完整名称匹配（忽略大小写、首尾空格和全半角），不做模糊匹配。若存在多个同名收藏夹，使用接口返回的第一个。
- 已投过币的视频不会自动补到 2 枚，以免产生非预期投币。
- B 站网页接口可能调整。遇到失败时展开「诊断日志」，日志只包含接口路径、状态码和文字结果，不包含登录凭据。

## 验证情况

- 已通过 JavaScript 语法检查。
- 使用真实接口验证王道课程可读取标题与标签，并正确判为「计算机考研」。
- 模拟流程覆盖：全新三连、全部已完成、投币上限、重复点赞、建夹网络异常后重查、CSRF 失效停止后续操作。
- 未在用户账号上擅自执行真实点赞、投币、收藏或建夹；首次使用时请在确实想三连的视频上核对实际结果。
